# 🩸 Life Savers Blood Bank

## About the Project

Life Savers Blood Bank is a web-based blood bank management system developed to help users find blood availability, register as blood donors, request blood, and contact the blood bank easily.

The project contains a frontend website and a Node.js backend for storing and managing information.

## Features

- 🏠 Home page
- ℹ️ About Us page
- 🩸 Blood donor registration
- ❤️ Blood donation information
- 🔍 Blood availability
- 🚑 Blood request form
- 📞 Contact page
- 💾 Backend data storage using JSON files
- 🌐 Online deployment
